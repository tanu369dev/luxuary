# Riders — Pre-Owned Luxury Motorcycles

A static marketplace site to buy and sell second-hand luxury bikes. Plain HTML/CSS/JS, no build step.

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Push this folder (index.html + images/) to a GitHub repo.
2. Settings → Pages → Deploy from branch → `main` / root.

## Notes
- Bike listings live in the `BIKES` array inside `index.html`.
- "Sell your bike" listings and the wishlist are saved in the visitor's browser (localStorage). To make listings visible to everyone, connect a backend (e.g. Supabase or Firebase).
